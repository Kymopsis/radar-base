# Home Assistant

Radar Base は MQTT ディスカバリーで Home Assistant に自動的に表示されます。ご自身の MQTT ブローカーを使います。
一般的なのは Home Assistant の **Mosquitto broker** アドオンです。Kymopsis はブローカーもクラウドも運用しません。データがネットワークの外に出ることはありません。

## 必要なもの

- **Mosquitto broker** アドオンと **MQTT** 連携を入れた Home Assistant、またはご自身で運用している別の MQTT ブローカー。
  ブローカーのアドレス、ポート（通常は 1883）、ユーザー、パスワードを控えておきます。
- **2.4 GHz** の Wi-Fi ネットワーク、または 2.4 GHz と 5 GHz が同じ名前のデュアルバンドネットワーク。ESP32-S3 には
  5 GHz の無線がありません。
- Radar Base ファームウェア 0.9.1 以降（[ブラウザからインストール](app)）。

## セットアップ

1. Wi-Fi に接続します：Radar Base アプリ（USB 経由、またはボードのホットスポット）を開き、デバイス設定、Wi-Fi。
2. デバイス設定のスマートホームで、ブローカーのアドレス、ポート、ユーザー、パスワードを入力し、MQTT をオンにします。
3. Home Assistant で 設定 → デバイスとサービス → MQTT を開きます。**Kymopsis Radar Base** がエンティティとともに表示されます。
   ほかに設定は不要です。

## エンティティ

| エンティティ | 種類 | 単位 / 値 | 元になるレーダーアプリ |
|---|---|---|---|
| 在室 | バイナリセンサー | オン / オフ | 3D 在室 |
| 人数 | センサー | 数 | 3D 在室 |
| 最も近い人 | センサー | m | 3D 在室 |
| エリア 1、エリア 2、エリア 3、エリア 4 | バイナリセンサー | オン / オフ | 3D 在室 |
| 転倒を検知 | バイナリセンサー | オン / オフ | 転倒検知 |
| 呼吸数 | センサー | /min | 呼吸と心拍 |
| 心拍数 | センサー | /min | 呼吸と心拍 |
| レーダーアプリ | センサー | 実行中のアプリ名 | すべて |
| 設置方法 | セレクト | 天井 / 壁 | 3D 在室 |
| レーダーを再起動 | ボタン | | すべて |

実行中のレーダーアプリが報告しない値は、空または不明のままになります。呼吸数と心拍数はウェルネス用途のみで、医療用途には使えません。

## オンラインとオフライン

ボードは可用性トピックを公開します。ボードで MQTT をオフにすると、デバイスはすぐに利用不可になります。
ボードの電源や Wi-Fi が切れた場合は、約 45 秒後にブローカーが利用不可として扱います。ボードが再接続すると自動的に戻ります。

## トラブルシューティング

| 問題 | 対処 |
|---|---|
| デバイスが表示されない | ボードのスマートホームのページが「接続済み」になっているか確認します。ブローカーのユーザーとパスワードも確認してください。 |
| ボードが Wi-Fi に接続できない | 2.4 GHz のネットワーク、または同じ名前のデュアルバンドネットワークを使ってください。5 GHz 専用のネットワークは使えません。 |
| `kymradar.local` が開かない | そのパソコンの VPN やプロキシが `.local` の名前を横取りすることがあります。オフにするか `.local` を直接接続にするか、ボードの IP アドレスを開いてください。 |
| 距離がフィートで表示される | Home Assistant は設定した単位系を使います。設定 → システム → 一般 → 単位系：メートル法。 |

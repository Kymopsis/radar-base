# 生データと独自のアルゴリズム

Radar Base は、レーダーの生データ（すべてのチャープ、2 つの受信チャンネル）を USB 経由で流せます。オープン版ファームウェアにはこのストリームとその設定が含まれますが、生データを表示・処理する PC ツールはまだ公開していません。

## オープン版ファームウェアでできること

| 機能 | 場所 |
|---|---|
| 生データの設定：チャープ、ゲイン、フィルター、アンテナ | アプリ → 生データとレーダー設定、またはコンソールで `cfg <key> <value>` |
| データリンクのセルフテスト：すべてのブロックを検査 | アプリ → 生データとレーダー設定 → **テストを実行** |
| 自分のコード向けの JSON 結果 | [JSON の結果と API](json-api) |

## アルゴリズムをどこで動かすか

まず PC でプロトタイプを作ります。次に、レーダー自身の FFT と CFAR のハードウェアで処理できるか確認します。できるなら、
レーダー上で動かして結果だけを外に出します。できなければ ESP32 で動かせるか確認し、どちらも無理なときだけ PC に残します。

## データリンクを確認する

アプリ → 生データとレーダー設定 → **テストを実行**。生データアプリを数秒間動かし、すべてのブロックを検査します。
破損ブロックと欠落ブロックは、どちらも 0 になるはずです。

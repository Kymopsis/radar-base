# Radar Base

Radar Base は、60 GHz ミリ波レーダーモジュールを、あなたのパソコン、スマホ、スマートホームにつなぎます。
レーダーの処理はレーダー自身のチップが行います。Radar Base はレーダーアプリを読み込み、結果をシンプルな JSON 形式に変換して、
USB と Wi-Fi で提供します。

[[cards]]
- **ビルド済みのレーダーアプリを動かす** | 人物位置の 3D 表示、転倒検知、呼吸と心拍。コーディング不要。 | getting-started
- **USB でブラウザーから使う** | つないで、Chrome か Edge でこのサイトを開くだけ。Wi-Fi は不要です。 | usb
- **自宅の Wi-Fi につなぐ** | 自宅のどのスマホやパソコンからでも http://kymradar.local で使えます。 | wifi
- **独自の連携を作る** | USB または WebSocket 経由で、どのプログラムからでも結果を JSON で読み取れます。 | json-api
[[/cards]]

## 全体の構成

[[diagram]]

| 部品 | 役割 |
|---|---|
| レーダーモジュール | レーダーアプリを実行します。各アプリは信号処理の全工程をレーダー上で行い、結果を報告します |
| Radar Base (ESP32-S3) | レーダーアプリを読み込み、結果を JSON に変換し、生データを流し、Web アプリを提供し、Wi-Fi に参加します |
| Web アプリ | タスクを選び、リアルタイムの結果を見て、設定を変えます。Wi-Fi でも USB でも同じアプリで、11 言語に対応します |
| 自分のコード | USB または WebSocket 経由で JSON の結果を読み取ります |
| スマートホーム | MQTT 経由の Home Assistant（近日対応）、ESPHome（その後） |

## 接続方法

| モード | 使う場面 | ガイド |
|---|---|---|
| USB | 最初の一歩、開発。どこでも使え、ネットワーク不要 | [ブラウザーで USB を使う](usb) |
| 自宅の Wi-Fi | 自宅のスマホやパソコンから普段使いする | [自宅の Wi-Fi](wifi) |
| ホットスポット | 最初のセットアップ、または自宅のネットワークに届かないとき | [ホットスポットのフォールバック](hotspot) |
| Home Assistant | オートメーション：照明、通知、ダッシュボード | [Home Assistant](home-assistant) |

Radar Base はクラウドアカウントを必要としません。レーダーのデータは自分のデバイスの中だけに残ります。

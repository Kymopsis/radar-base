# FAQ とトラブルシューティング

## アプリは接続できるが結果が表示されない

- レーダーのキャリアボードに電源は入っていますか？ 先に Radar Base の電源を入れましたか？ 診断 → **レーダーを再起動** を開いてください。
- 診断 → **レーダーのバージョンを確認**：応答があれば、結果用の配線（RX0/TX0）は問題ありません。

## シナリオの読み込みに失敗する

- 診断 → **ブートリンクを確認**。応答がない場合は、RX1、TX1、RST、P12、P19 のジャンパーワイヤーが緩んでいることが多いです。
- ワイヤーを挿し直してください。ジャンパーワイヤーは接触不良になりやすいです。長さは 15 cm 以内にしてください。

## 生データのセルフテストでブロックの破損や欠落が出る

- SPI CLK と MOSI の配線を確認してください（MISO ではなく MOSI）。そのすぐ横にグラウンド線も添えます。
- SPI 速度を下げます：コンソールで `cfg spi 12.5`。

## すべてのブロックが不良で、00 または FF だけになる

データ線がキャリアボードの MISO ピンにつながっています。**MOSI** につなぎ替えてください。

## ブラウザーに USB ポートが表示されない

- コントローラーの **USB** と書かれたポートを使います。UART ではありません。
- シリアルターミナルを閉じてください。ポートを使えるのは一度に 1 つのプログラムだけです。
- デスクトップ PC の Chrome または Edge を使ってください。

## http://kymradar.local が開かない

一部の Android スマホは `.local` の名前を解決できません。デバイス設定 → 自宅の Wi-Fi に表示される IP アドレスを使ってください。

## 呼吸数や心拍数が空のまま

レーダーの正面 0.5-1.5 m の位置で、胸をレーダーに向けて静かに座るか横になり、約 20 秒待ってください。これらの値はウェルネス用途のみで、医療用途には使えません。

## 人は表示されるのにエリアが点灯しない（またはその逆）

エリアとトラッキングは、レーダーの別々の出力です。ほとんど動かない人はトラッキングから外れることがありますが、エリアは使用中のままです。
数字を安定させるため、アプリは直近の短い間の最大人数を表示します。

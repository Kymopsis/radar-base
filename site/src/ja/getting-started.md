# はじめに

このガイドでは、箱から出して、リアルタイムのレーダー結果が見えるまでを約 15 分で説明します。

## 必要なもの

- Radar Base コントローラー（ESP32-S3 ボード）と、キャリアボードに載った 60 GHz レーダーモジュール
- ジャンパーワイヤー 10 本（メス-メス）- キットに同梱
- USB ケーブル 2 本：Radar Base 用と、レーダーのキャリアボードへの給電用
- Chrome または Edge が動くパソコン（Windows、macOS、Linux、ChromeOS）

## 1. レーダーのキャリアボードを準備する

キャリアボードのシリアルヘッダー（J9）と、P19 / GND / P12 のブートヘッダーから、ジャンパーキャップをすべて外します。
外さないと、キャリアボード自身の USB シリアルチップが同じ配線で Radar Base と競合します。

## 2. 配線する

最初にすべての電源を切ります。**GND を最初に**つなぎ、それから残りをつなぎます。ラベルはレーダーのキャリアボードに印刷されたものです。

[[wiring]]

| Radar Base のピン | キャリアボードのラベル | 用途 |
|---|---|---|
| GND | GND | 共通グラウンド（最初につなぐ） |
| GPIO17 | RX0 | レーダーアプリへのコマンド |
| GPIO18 | TX0 | レーダーアプリからの結果 |
| GPIO15 | RX1 | レーダーへのアプリの読み込み |
| GPIO16 | TX1 | 読み込み中の応答 |
| GPIO4 | RST | レーダーのリセット |
| GPIO5 | P12 | ブート選択（データ選択も兼ねる） |
| GPIO6 | P19 | ブート選択 |
| GPIO12 | SPI CLK | 生データのクロック（生データ用のみ） |
| GPIO11 | SPI MOSI | 生データ（MISO は使わない） |

レーダーはキャリアボード自身の電源で動きます（最大約 600 mA）。コントローラーボードの 3V3 ピンから給電しないでください。

## 3. 正しい順番で電源を入れる

1. コントローラーの **USB** と書かれたポートをパソコンにつなぎます。（UART と書かれたポートは、コントローラー自身のファームウェア更新専用です。）
2. そのあとでレーダーのキャリアボードに給電します。

Radar Base は起動するとすぐレーダーのブートピンを設定するため、レーダーは後から起動する必要があります。順番を逆にしてしまったら、
診断を開いて **レーダーを再起動** を押してください。

## 4. 動かしてみる

1. Chrome または Edge で[アプリ](app/)を開き、**USB 接続** を押して、「USB JTAG/serial」という名前のポートを選びます。
2. **シナリオを実行** → **3D 在室・人物トラッキング** を選びます。
3. レーダーの前を歩きます。あなたの位置が青い点で表示されます。

次は：普段使いなら[自宅の Wi-Fi](wifi)、独自のアルゴリズムを作るなら[生データ](raw-data)へ。

# ブラウザーで USB を使う

Radar Base アプリは、パソコンの Chrome または Edge で動き、USB ケーブル（Web Serial）を通してボードと通信します。
インストールは不要で、Wi-Fi も使いません。

## 手順

1. コントローラーの **USB** ポートをパソコンにつなぎます。
2. Chrome または Edge で **[radar.kymopsis.com/app](app/)** を開きます。
3. 上部バーの **USB 接続** を押し、「USB JTAG/serial debug unit」を選びます。
4. ステータスが緑になります。ホームでタスクを選びます。

ブラウザーは、サイトごとに一度だけポートの使用許可を尋ねます。パソコンのそれ以外の内容は共有されません。

## USB で使える機能

| 機能 | USB の場合 |
|---|---|
| シナリオの実行、ライブビュー、シナリオ設定 | 可 |
| 生データの設定とデータリンクのセルフテスト | 可 |
| レーダーへのファームウェア書き込み（開発キット） | 可 |
| 自宅の Wi-Fi の設定 | 可（ネットワーク名とパスワードに空白を含めない） |
| ファームウェアファイルのアップロードや削除 | 不可 - Wi-Fi で行ってください |

## 同時に使えるのは 1 つのプログラムだけ

USB ポートを開けるのは 1 つのプログラムだけです。ブラウザーで接続する前にシリアルターミナルを閉じてください。
逆の場合も同じです。

## ブラウザー

Web Serial は、デスクトップの Chrome、Edge、その他の Chromium 系ブラウザーで使えます。Safari と Firefox は非対応です。
それらやスマホでは[自宅の Wi-Fi](wifi)を使ってください。

# Сырые данные и ваши алгоритмы

Radar Base может передавать по USB сырые данные радара (каждый чирп, оба приёмных канала). Открытая прошивка включает этот поток и его настройки; инструмент для ПК, который показывает и обрабатывает сырые данные, пока не опубликован.

## Что даёт открытая прошивка

| Возможность | Где |
|---|---|
| Настройки сырых данных: чирп, усиление, фильтры, антенны | Приложение → Сырые данные и настройки радара, или консоль `cfg <key> <value>` |
| Самотест канала данных: проверяется каждый блок | Приложение → Сырые данные и настройки радара → **Запустить тест** |
| Результаты в формате JSON для вашего собственного кода | [Результаты JSON и API](json-api) |

## Где запускать алгоритм

Сначала сделайте прототип на ПК. Затем проверьте, справится ли с задачей собственное аппаратное обеспечение радара для FFT и CFAR; если да,
алгоритм должен работать на радаре, а наружу выходят только результаты. Иначе проверьте ESP32, и оставляйте алгоритм только на ПК, если не подходит ни то, ни другое.

## Проверьте канал данных

Приложение → Сырые данные и настройки радара → **Запустить тест**. Он на несколько секунд запускает приложение сырых данных и проверяет каждый блок:
повреждённых и пропущенных блоков должно быть 0.

Партии, предварительно прошитые модули или индивидуальная прошивка: [Kymopsis B2B](https://kymopsis.com/b2b/?utm_source=radar-site&utm_medium=docs&utm_campaign=radar-base)

# Radar Base

Radar Base подключает радарный модуль 60 GHz (mmWave) к вашему компьютеру, телефону и умному дому.
Радарную работу выполняет собственный чип радара; Radar Base загружает в него радарные приложения, превращает их результаты
в один простой формат JSON и отдаёт их по USB и Wi-Fi.

## Проверенное оборудование

| Оборудование | Статус |
|---|---|
| Комплект разработчика Kymopsis Radar Base | Проверено. Работает сразу; профиль платы включён |
| DIY-сборка Kymopsis: ESP32-S3 DevKit и радарный модуль 60 ГГц на плате-носителе, подключённые как в разделе [Начало работы](getting-started) | Проверено. Работает сразу; профиль платы включён |
| Другие платы и радарные модули | Не проверено. Сверьте назначение выводов и профиль платы самостоятельно; тогда приложение покажет «Неизвестная плата, углы не откалиброваны» |

## Как всё устроено

[[diagram]]

| Часть | Что делает |
|---|---|
| Радарный модуль | Выполняет радарные приложения: каждое приложение проводит всю цепочку обработки сигнала на радаре и сообщает результаты |
| Radar Base (ESP32-S3) | Загружает радарные приложения, переводит результаты в JSON, передаёт сырые данные, отдаёт веб-приложение, подключается к вашему Wi-Fi |
| Веб-приложение | Выбор задачи, живые результаты, настройки. Одно и то же приложение по Wi-Fi и по USB, на 11 языках |
| Ваш собственный код | Читает результаты JSON по USB или WebSocket |
| Умный дом | Home Assistant через MQTT (автообнаружение), компонент ESPHome |

## Способы подключения

| Режим | Когда использовать | Руководство |
|---|---|---|
| USB | Первые шаги и разработка. Работает везде, сеть не нужна | [USB в браузере](usb) |
| Домашний Wi-Fi | Повседневное использование с телефонов и компьютеров дома | [Домашний Wi-Fi](wifi) |
| Точка доступа | Первая настройка или когда домашняя сеть недоступна | [Резервная точка доступа](hotspot) |
| Home Assistant | Автоматизации: свет, оповещения, панели | [Home Assistant](home-assistant) |

Radar Base никогда не требует облачной учётной записи. Данные радара остаются на ваших устройствах.

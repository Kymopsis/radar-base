# Модуль записи радара для dev-kit

Прошивка Radar Base выпускается в двух редакциях из одного исходного кода:

| Редакция | Что умеет |
|---|---|
| Open | Всё, что описано на этом сайте: запуск любых радарных приложений из памяти радара, JSON, веб-приложение, Wi-Fi, умный дом |
| Dev kit | Open + один дополнительный модуль, который пишет во флеш-память самого радара |

## Что делает модуль

Если записать приложение во флеш радара, оно запускается само при включении питания, без предварительной загрузки через Radar Base.
Перед каждой записью модуль делает резервную копию текущей флеш-памяти радара; если копия не создалась, ничего не записывается.
Копии можно вернуть из приложения в любой момент.

## Как поставляется прошивка dev-kit

Прошивка dev-kit предзагружена на плату dev-kit. Об обновлениях покупателей уведомляют по электронной почте; прошивка dev-kit не доступна для публичной загрузки. Открытая прошивка будет опубликована в виде исходного кода в публичном репозитории; ссылка появится на этой странице после публикации.

## Пакетная прошивка

Для множества модулей подряд: выберите прошивку один раз, затем подключайте модули один за другим. Каждый модуль определяется, при необходимости копируется, записывается, проверяется, запускается из своей флеш-памяти, и у него запрашивается версия. Страница и индикатор на плате показывают PASS или FAIL, счётчик растёт, а на каждый модуль приходится одна строка в журнале CSV, который можно скачать.

## Чего он не делает

- Не подключается к интернету.
- Не собирает, не хранит и не отправляет никакие данные.
- Больше ничего в прошивке от него не зависит.

Он закрыт, потому что небольшая вспомогательная программа, которую он загружает в радар для записи, не принадлежит нам и мы не можем её публиковать.
На устройствах dev-kit эта программа хранится в зашифрованном виде с ключом, уникальным для каждого устройства.

## Без него

Любое радарное приложение также работает из памяти радара на открытой прошивке (Запустить сценарий). Вы теряете только удобство
«запускается само без Radar Base». Открытая прошивка, приложение и формат JSON открыты по замыслу; приложение и формат JSON описаны на этом сайте.

# ESPHome

> 預計在 Home Assistant 的 MQTT 整合之後推出。

ESPHome 外部元件會讓你像其他 ESPHome 裝置一樣，用 YAML 描述 Radar Base。它使用與應用程式和 MQTT 相同的結果
（人數、區域、跌倒、呼吸和心率），因此可以和你自己的 ESPHome 感測器與自動化搭配使用。

在此之前，請使用[透過 MQTT 連接 Home Assistant](home-assistant)，或直接讀取 JSON 結果（[JSON 與 API](json-api)）。

大量採購、預燒錄模組或客製韌體： [Kymopsis B2B](https://kymopsis.com/b2b/?utm_source=radar-site&utm_medium=docs&utm_campaign=radar-base)

# 下載

## 韌體

最簡單的方法是[首頁](app)上的 **安裝韌體** 按鈕（桌面版 Chrome 或 Edge，開發板透過 USB 連接）。相同的檔案也在 GitHub 上：[Radar Base 發佈頁](https://github.com/Kymopsis/radar-base/releases)。
韌體 0.9.2 及更新版本包含雷達應用（3D 人員存在；呼吸和心率）。

## Windows 版 Radar Studio

[下載 Windows 版 Radar Studio 0.9.1](https://github.com/Kymopsis/radar-base/releases/download/v0.9.1/KymopsisRadarStudio-0.9.1.exe)
（64 位元，約 60 MB，無需安裝；SHA-256 見
[發佈頁](https://github.com/Kymopsis/radar-base/releases/tag/v0.9.1)）。

| 適用於 | 功能 |
|---|---|
| 任意 Radar Base | 透過 USB 連線、情境檢視、常用設定、智慧家庭（MQTT）設定 |
| Kymopsis Radar Base 開發套件 | 另外還有原始資料、距離-都卜勒、波形和濾波器設定、你自己的演算法、生命徵象 / HRV |

### Windows 提示「Windows 已保護您的電腦」

Radar Studio 目前還沒有程式碼簽章，所以 Windows SmartScreen 第一次可能會攔截它。點選**其他資訊**，然後點選**仍要執行**。如果想確認檔案是原版，請對照發佈頁核對檔案的 SHA-256。

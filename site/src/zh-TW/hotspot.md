# 熱點備援

Radar Base 只在必要時才開啟自己的 Wi-Fi 網路：尚未儲存家用網路，或已儲存的網路連續 30 秒連不上時。它用於首次設定，
以及在外面做示範。

## 連線

1. 在手機或筆電上加入網路 **KymRadarBase-xxxx**（密碼 `kymradar`）。
2. 設定頁面通常會自動開啟。如果沒有，請開啟 **http://192.168.4.1**。

連線期間，手機無法透過這個網路上網，這是正常的。大多數手機會跳出提示，並繼續保持行動數據可用。

## 從這裡設定家用 Wi-Fi

裝置設定 → 家用 Wi-Fi → 選擇你的網路 → 輸入密碼 → 連線。然後讓手機重新連回家裡的 Wi-Fi，開啟 http://kymradar.local
（[家用 Wi-Fi](wifi)）。

## 何時關閉

家用網路可用，且沒有手機連在熱點上時，熱點會自動關閉。

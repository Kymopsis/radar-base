# 원시 데이터와 나만의 알고리즘

Radar Base는 레이더의 원시 데이터(모든 처프, 두 수신 채널)를 USB로 스트리밍할 수 있습니다. 오픈 펌웨어에는 이 스트림과 그 설정이 포함되어 있습니다. Windows용 Radar Studio로 원시 데이터를 보고 처리하며, 개발 키트가 있으면 이 보기들을 열 수 있습니다([다운로드](downloads)).

## 오픈 펌웨어가 제공하는 것

| 기능 | 위치 |
|---|---|
| 원시 데이터 설정: 처프, 게인, 필터, 안테나 | 앱 → 원시 데이터 및 레이더 설정, 또는 콘솔에서 `cfg <key> <value>` |
| 데이터 링크 자가 테스트: 모든 블록 검사 | 앱 → 원시 데이터 및 레이더 설정 → **테스트 실행** |
| 직접 만든 코드용 JSON 결과 | [JSON 결과와 API](json-api) |

## 알고리즘을 어디서 실행할까

먼저 PC에서 프로토타입을 만드세요. 그다음 레이더 자체의 FFT와 CFAR 하드웨어로 처리할 수 있는지 확인합니다. 가능하면
레이더에서 실행하고 결과만 내보냅니다. 아니면 ESP32에서 가능한지 확인하고, 둘 다 안 될 때만 PC에 두세요.

## 데이터 링크 확인

앱 → 원시 데이터 및 레이더 설정 → **테스트 실행**. 원시 데이터 앱을 몇 초간 실행하며 모든 블록을 검사합니다.
손상된 블록과 누락된 블록은 둘 다 0이어야 합니다.

대량 구매, 사전 기록된 모듈, 맞춤 펌웨어: [Kymopsis B2B](https://kymopsis.com/b2b/?utm_source=radar-site&utm_medium=docs&utm_campaign=radar-base)

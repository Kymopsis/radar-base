# 개발 키트 레이더 기록 모듈

Radar Base 펌웨어는 같은 소스로 빌드한 두 가지 에디션이 있습니다.

| 에디션 | 할 수 있는 일 |
|---|---|
| 오픈 | 이 사이트에서 다루는 모든 것: 레이더 메모리에서 모든 레이더 앱 실행, JSON, 웹 앱, Wi-Fi, 스마트홈 |
| 개발 키트 | 오픈 + 레이더 자체 플래시에 기록하는 추가 모듈 하나 |

## 모듈이 하는 일

앱을 레이더 플래시에 기록하면, Radar Base가 먼저 불러오지 않아도 전원을 켤 때 레이더가 스스로 시작합니다.
모듈은 기록할 때마다 레이더의 현재 플래시를 먼저 백업합니다. 백업에 실패하면 아무것도 기록하지 않습니다.
백업은 앱에서 언제든 되돌릴 수 있습니다.

## 개발 키트 펌웨어 제공 방식

개발 키트 펌웨어는 개발 키트 보드에 미리 기록되어 제공됩니다. 업데이트는 구매자에게 이메일로 안내하며, 개발 키트 펌웨어는 공개 다운로드로 제공되지 않습니다. 오픈 펌웨어는 소스 코드로 공개되어 있습니다: [github.com/Kymopsis/radar-base](https://github.com/Kymopsis/radar-base).

## 일괄 기록

모듈을 연달아 많이 처리할 때: 펌웨어를 한 번 고르고 모듈을 하나씩 연결합니다. 각 모듈은 감지되고, 필요하면 백업되고, 기록되고, 검증되고, 플래시에서 시작되어 버전을 확인합니다. 화면과 보드의 표시등에 PASS 또는 FAIL이 나타나고 카운터가 올라가며, 모듈마다 내려받을 수 있는 CSV 로그에 한 줄씩 남습니다.

## 하지 않는 일

- 인터넷에 연결하지 않습니다.
- 어떤 데이터도 수집, 저장, 전송하지 않습니다.
- 펌웨어의 다른 부분은 이 모듈에 의존하지 않습니다.

비공개인 이유는 기록할 때 레이더에 불러오는 작은 도우미 프로그램을 우리가 공개할 수 없기 때문입니다.
개발 키트 장치에서는 이 도우미가 장치마다 고유한 키로 암호화되어 저장됩니다.

## 모듈이 없으면

오픈 펌웨어에서도 모든 레이더 앱을 레이더 메모리에서 실행할 수 있습니다(시나리오 실행). 잃는 것은
"Radar Base 없이도 스스로 시작한다"는 편의뿐입니다. 오픈 펌웨어, 앱, JSON 형식은 처음부터 개방형으로 설계되었으며, 앱과 JSON 형식은 이 사이트에 설명되어 있습니다.

대량 구매, 사전 기록된 모듈, 맞춤 펌웨어: [Kymopsis B2B](https://kymopsis.com/b2b/?utm_source=radar-site&utm_medium=docs&utm_campaign=radar-base)

# 다운로드

## 펌웨어

가장 쉬운 방법은 [홈](app)의 **펌웨어 설치** 버튼입니다(데스크톱의 Chrome 또는 Edge, 보드는 USB 연결). 같은 파일은 GitHub에도 있습니다: [Radar Base 릴리스](https://github.com/Kymopsis/radar-base/releases).
펌웨어 0.9.2 이상에는 레이더 앱(3D 재실 감지, 호흡 및 심박수)이 포함되어 있습니다.

## Windows용 Radar Studio

[Windows용 Radar Studio 0.9.1 다운로드](https://github.com/Kymopsis/radar-base/releases/download/v0.9.1/KymopsisRadarStudio-0.9.1.exe)
(64비트, 약 60 MB, 설치 불필요. SHA-256은
[릴리스](https://github.com/Kymopsis/radar-base/releases/tag/v0.9.1)에 있습니다).

| 지원 대상 | 기능 |
|---|---|
| 모든 Radar Base | USB로 연결, 시나리오 보기, 자주 쓰는 설정, 스마트홈(MQTT) 설정 |
| Kymopsis Radar Base 개발 키트 | 원시 데이터, 거리-도플러, 파형 및 필터 설정, 나만의 알고리즘, 활력 징후 / HRV도 지원 |

### 'Windows의 PC 보호'

Radar Studio는 아직 코드 서명이 되어 있지 않아 Windows SmartScreen이 처음에 실행을 막을 수 있습니다. **추가 정보**를 선택한 다음 **실행**을 선택하세요. 원본인지 확인하고 싶다면 파일의 SHA-256을 릴리스 페이지와 비교하세요.

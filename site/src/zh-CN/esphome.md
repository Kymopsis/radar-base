# ESPHome

> 计划在 Home Assistant 的 MQTT 集成之后推出。

ESPHome 外部组件会让你像其他 ESPHome 设备一样，用 YAML 描述 Radar Base。它使用与应用和 MQTT 相同的结果
（人数、区域、跌倒、呼吸和心率），因此可以和你自己的 ESPHome 传感器与自动化搭配使用。

在此之前，请使用[通过 MQTT 接入 Home Assistant](home-assistant)，或直接读取 JSON 结果（[JSON 与 API](json-api)）。

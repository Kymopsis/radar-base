# 开发套件雷达写入模块

Radar Base 固件有两个版本，源自同一份源码：

| 版本 | 能做什么 |
|---|---|
| 开放版 | 本站介绍的一切：从雷达内存运行所有雷达应用、JSON、网页应用、Wi-Fi、智能家居 |
| 开发套件版 | 开放版 + 一个额外模块，可写入雷达自己的闪存 |

## 模块的作用

把应用写入雷达闪存后，雷达上电就会自己启动，不需要 Radar Base 先加载。模块在每次写入前都会备份雷达当前的闪存；
备份失败就不会写入任何内容。备份可随时在应用里还原。

## 开发套件固件如何交付

开发套件固件已预装在开发套件板上。更新会通过电子邮件通知买家；开发套件固件不提供公开下载。开放版固件将以源码形式发布到公开仓库，发布后会在本页给出链接。

## 批量写入

要连续处理多个模块：先选一次固件，然后逐个接上模块。每个模块都会被检测、按需备份、写入、校验、从闪存启动，并读取其版本。页面和板上的指示灯显示 PASS 或 FAIL，计数器累加，每个模块在可下载的 CSV 日志里占一行。

## 它不做什么

- 不连接互联网。
- 不收集、存储或发送任何数据。
- 固件的其他部分都不依赖它。

它是闭源的，因为写入时加载到雷达里的那个小型辅助程序不属于我们，不能公开。在开发套件设备上，
该辅助程序以每台设备独有的密钥加密存放。

## 没有它

开放版固件同样可以从雷达内存运行每个雷达应用（运行场景）。你只是少了“不需要 Radar Base 就能自己启动”
这一项便利。开放版固件、应用和 JSON 格式本身就是开放的设计，应用和 JSON 格式都在本站有说明。

# 常见问题与故障排除

## 应用已连接，但没有结果

- 雷达载板通电了吗？是否先给 Radar Base 上电？打开“诊断”→ **重启雷达**。
- “诊断”→ **读取雷达版本**：有回复说明结果线（RX0/TX0）正常。

## 加载场景失败

- “诊断”→ **检查启动连接**。没有回复通常是 RX1、TX1、RST、P12 或 P19 上的杜邦线松了。
- 重新插紧导线；杜邦线很容易接触不良。长度请控制在 15 cm 以内。

## 原始数据自检显示数据块损坏或缺失

- 检查 SPI CLK 和 MOSI 导线（是 MOSI，不是 MISO），并在旁边并行一根地线。
- 降低 SPI 速度：控制台输入 `cfg spi 12.5`。

## 每个数据块都是坏的，内容只有 00 或 FF

数据线接到了载板的 MISO 引脚。请改接到 **MOSI**。

## 浏览器里看不到 USB 端口

- 使用控制板上标有 **USB** 的端口，不是 UART。
- 关闭任何串口终端：一个端口同一时间只能被一个程序使用。
- 请在桌面电脑上使用 Chrome 或 Edge。

## http://kymradar.local 打不开

部分 Android 手机无法解析 `.local` 名称。请使用“设备设置 → 家庭 Wi-Fi”下显示的 IP 地址。

## 呼吸或心率一直为空

请在雷达前方 0.5-1.5 m 处静坐或静卧，胸部朝向雷达，等待约 20 秒。这些读数仅供健康养生用途，不可用于医疗。

## 显示有人但区域没亮（或相反）

区域和追踪是雷达的两路独立输出。一个完全静止的人可能从追踪中消失，而区域仍显示有人。应用会显示最近一小段时间内的
最大人数，让数字保持稳定。

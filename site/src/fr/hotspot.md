# Point d'accès de secours

Radar Base n'ouvre son propre réseau Wi-Fi que lorsqu'il le faut : quand aucun réseau domestique n'est encore
enregistré, ou quand celui qui l'est est resté injoignable pendant 30 secondes. Il sert à la première configuration et
aux démonstrations hors de chez vous.

## Se connecter

1. Sur votre téléphone ou ordinateur portable, rejoignez le réseau **KymRadarBase-xxxx** (mot de passe `kymradar`).
2. La page de configuration s'ouvre en général toute seule. Sinon, ouvrez **http://192.168.4.1**.

Tant que vous êtes connecté, votre téléphone n'a pas d'accès Internet via ce réseau ; c'est normal. La plupart des
téléphones affichent un avis et gardent les données mobiles disponibles.

## Configurer le Wi-Fi domestique depuis ici

Réglages de l'appareil → Wi-Fi domestique → choisissez votre réseau → mot de passe → Connecter. Reconnectez ensuite
votre téléphone à votre Wi-Fi domestique et ouvrez http://kymradar.local ([Wi-Fi domestique](wifi)).

## Quand il s'éteint

Dès que le réseau domestique fonctionne et qu'aucun téléphone n'est connecté au point d'accès.

Volumes, modules préflashés ou firmware sur mesure : [Kymopsis B2B](https://kymopsis.com/b2b/?utm_source=radar-site&utm_medium=docs&utm_campaign=radar-base)

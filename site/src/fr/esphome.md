# ESPHome

> Prévu après l'intégration MQTT de Home Assistant.

Un composant externe ESPHome vous permettra de décrire Radar Base en YAML comme n'importe quel autre appareil ESPHome. Il
utilisera les mêmes résultats que l'appli et MQTT (personnes, zones, chute, fréquence respiratoire et cardiaque), pour
que vous puissiez les combiner avec vos propres capteurs et automatisations ESPHome.

D'ici là, utilisez [Home Assistant via MQTT](home-assistant), ou lisez directement les résultats JSON ([JSON et API](json-api)).

Volumes, modules préflashés ou firmware sur mesure : [Kymopsis B2B](https://kymopsis.com/b2b/?utm_source=radar-site&utm_medium=docs&utm_campaign=radar-base)
